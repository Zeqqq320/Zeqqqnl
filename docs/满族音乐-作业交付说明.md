曲库文件：`webui/ethnos_cache/t03_满族音乐.json`（专题曲库，通过 `/api/topics` 挂载）

| 项目 | 结果 |
| --- | --- |
| 变动前 | 83 首 |
| 变动后 | **96 首** |
| 净增 | **+13 首**（无删除） |
| 总时长 | 273.0 分钟 → 317.4 分钟 |
| 涉及歌手 | 33 位 → 42 位 |

**新增 13 首的构成**

| 类别 | 曲目 |
| --- | --- |
| 满语民歌 | 满语版《八音波罗》、悠车调、摇篮曲（满语） |
| 萨满祭祀 | 东北萨满神调、萨满神曲、萨满帮兵调、萨满鼓、祭天神歌 |
| 满族器乐 | 满族口弦系列、满族摇篮曲（竖琴弹唱） |
| 民歌采集 | B6 摇篮曲（满族）、满族茉莉花 |
| 传统歌舞 | Dancing Song 庆隆舞 |

**维护流程**（脚本在 `manchu/` 目录，可重复执行）

1. `probe.py` / `run_one.sh` — 调用后端 `/api/probe/start` 按关键词（满族民歌、满语歌曲、萨满神调…）联网检索候选，结果落盘到 `manchu/raw/`。采用**异步后台 + 轮询**模式，因为同步大响应会被网络策略掐断。
2. 人工核定：按"满族传统/满语"为准入标准，剔除现代乐队"萨满(Saman)"的流行歌、藏族蒙古族歌曲、主旋律创作、满语佛教咒语、白族八角鼓、网络翻唱。
3. `add_tracks.py` — 按"曲名+歌手"去重后写入曲库，自动备份旧版本。
4. `gen_report.py` — 生成变动统计。

> 关键经验：八音赫赫、阿克善、叶筱希等满族歌手的大部分曲目在首次建库时已抓取，入库前必须做去重，否则会把已有曲目误判为新增。

## 三、UI 页面设计

文件：`webui/templates/manchu.html` + `webui/static/manchu.css` + `webui/static/manchu.js`

系统未安装满文字体（会渲染成方框），因此满族元素**全部用图形语言表达**：

| 设计元素 | 满族依据 | 实现 |
| --- | --- | --- |
| **八旗 ↔ 音源** | 正黄/镶黄/正白/镶白/正红/镶红/正蓝/镶蓝 | 八个音源各对应一旗，每首曲目左侧色点即"旗属"，侧栏有图例与实时计数——装饰同时承载信息 |
| **白山黑水** | 长白山、黑龙江，满族发祥地 | 底部层叠山形剪影，播放时轻微起伏 |
| **萨满神鼓** | 满族萨满祭祀的核心法器 | 播放键做神鼓造型，播放时鼓面持续泛起涟漪 |
| **海东青** | 满族神鹰，渔猎文化图腾 | 品牌 Logo 线稿 + 萨满神鼓式双环 |
| **歌词竖排** | 满文自上而下、自右而左书写 | 可切换 `writing-mode: vertical-rl` |
| **匾额标题 / 回纹刻度** | 满族建筑装饰与回纹传统 | 标题匾额化处理，进度条用回纹刻度 |
| **昼夜切换** | 萨满"夜祭" | 日间宣纸底 / 夜间祭礼模式 |

界面布局：顶栏（搜索）｜左侧栏（全部·收藏·正在播放）｜中间曲目表（序号·曲名·歌手·专辑·时长）｜右侧歌词栏｜底部播放条。留白充足，尊重 `prefers-reduced-motion`。

功能：搜索、三种排序、播放/暂停、上下曲、进度拖动、音量、顺序·单曲循环·随机、LRC 歌词逐行高亮、收藏（本地+服务端双份）、键盘快捷键（空格 / ←→ / /）。

## 四、dmg 安装包封装

**封装角色：由 WorkBuddy 专家中心选定的高级全栈工程师专家（`fullstack-dev`）承担封装方案设计与交付前技术审查。**

| 项目 | 结果 |
| --- | --- |
| 产物 | `满族音乐-安装盘.dmg`（UDZO 压缩，约 54 MB） |
| 应用 | `/Applications/满族音乐.app`（约 161 MB） |
| 运行时 | python-build-standalone 3.13 便携 Python，内嵌于 app，目标机器无需安装 Python |
| 端口 | 8767（与"山河回响"完整版 8766 互不干扰） |
| 曲库 | 仅含满族专题 96 首，不含其他民族库 |
| 签名 | ad-hoc 签名，`codesign --verify --deep --strict` 通过 |

**技术要点**

- **单实例锁**：`mkdir server.lock` 原子竞争 + `exec` 顶替 shell 保持 PID 一致，可用 `kill -0` 精确判活。
- **字节码外移**：`PYTHONDONTWRITEBYTECODE=1` + `PYTHONPYCACHEPREFIX` 指向数据目录。ad-hoc 签名的 bundle 内多出任何文件都会破坏封印，被 Gatekeeper 判为"已损坏"——这是最容易踩的坑，已彻底解决（包内 .pyc 数为 0）。
- **安装盘布局**：用 dmgbuild 把 `.DS_Store` 与背景图烧进镜像，挂载即呈现"左侧 app、右侧 Applications、中间箭头"的可拖拽布局。
- **直链过期自愈**：曲库里 CDN 直链会失效，新增 `/api/resolve` 按曲名重新联网搜索并换新源，前端自动续播。

**技术审查报告**：`docs/满族音乐-封装技术审查报告.md`（由全栈工程师专家出具，含架构评价、问题清单、封装与签名结论）。

审查中发现的**致命问题本轮已修复**：新增接口与满族前端资源此前只存在于 `/Applications` 的包体内，源树未回写，导致构建脚本无法从零复现。现已将后端主程序、`static/`、`templates/manchu.html`、96 首曲库全部回写源树，并在 `packaging/build_app.sh` 补上 static 的同步步骤。

另修复 4 处缺陷：`/api/resolve` 的 `dur` 参数异常导致 500、歌词三位毫秒格式整体偏移、换源期间切歌会播错曲目、`/api/probe/start` 的 `outdir` 未校验（现限定在 `~/WorkBuddy` 或 `/tmp` 之下）。

**已知限制**：ad-hoc 签名未经过苹果公证，`spctl` 判定为 rejected。本机双击可直接打开；分发给他人时需右键 → 打开 → 确认，或执行 `xattr -dr com.apple.quarantine /Applications/满族音乐.app`。
