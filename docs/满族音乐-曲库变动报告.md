## 八、维护方式

| 操作 | 命令 |
| --- | --- |
| 检索候选 | `bash 曲库维护/run_one.sh <序号> "<关键词>"` |
| 预览新增 | `python3 曲库维护/add_tracks.py --dry-run` |
| 写入新增 | `python3 曲库维护/add_tracks.py` |
| 生成报告 | `python3 曲库维护/gen_report.py` |

新增曲目须先写入 `add_tracks.py` 的 `SELECTED` 清单（曲名关键字 / 歌手关键字 / 音源），
脚本会自动去重，已存在的曲目跳过，写入前自动备份到 `曲库备份/`。

## 九、数据健康提示

- 曲库条目保存的是**抓取瞬间的 CDN 直链**，酷狗/酷我/咪咕等通常数小时至数天后失效。
- 失效后播放器会调用 `/api/resolve` 按「曲名 + 歌手 + 时长」重新联网搜索并换源续播，用户无感。
- 因此曲库文件无需频繁重建，条目元数据长期有效，链接由运行时自愈。
